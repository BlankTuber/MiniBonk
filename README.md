# MiniBonk

Third-person survivor prototype. Fight waves of enemies, collect upgrades, survive as long as possible.

## Systems

| System      | What it covers                                                             |
|-------------|----------------------------------------------------------------------------|
| Combat      | Auto-attack projectiles, dash attack, orbital stones, enemy contact damage |
| Progression | XP/leveling, card selection, unlocks, stat upgrades with caps              |
| Economy     | Coin drops, chests, magnet radius                                          |
| Enemies     | Basic chasers, bosses with ground attacks, time-based scaling              |
| UI          | Health/XP bars, card selection, interaction prompts, game over screen      |

## Tech

- Unreal Engine 5.7
- C++
